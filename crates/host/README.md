# watoots

Sandboxed plugin host for native applications on the WebAssembly component model, built on Wasmtime.

**Status: name reserved, nothing here yet (v0.0.0).** This is part of
[watoots](https://crates.io/crates/watoots), a batteries-included plugin host for
native applications on the WebAssembly component model (built on Wasmtime), plus
a WIT-level record/replay tool. A real 0.1 is in development; until then this
crate intentionally has no API.
